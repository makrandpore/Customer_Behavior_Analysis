# Data Analytics Project

## Overview

This project demonstrates an end-to-end data analytics workflow using Python, SQL, Power BI, and presentation tools. It covers data loading, exploratory data analysis (EDA), data cleaning, SQL analysis, dashboard creation, and reporting to generate meaningful business insights.

---

## Dataset

The dataset contains structured business data used for analysis. It includes multiple attributes such as customer information, products, sales, ratings, and other relevant fields.

**Dataset Features**

* Structured CSV/Excel format
* Multiple columns with numerical and categorical data
* Suitable for analytics, visualization, and reporting

## Project Workflow

### 1. Data Loading

* Imported the dataset into Python.
* Inspected data types and structure.

### 2. Exploratory Data Analysis (EDA)

* Checked dataset dimensions.
* Generated summary statistics.
* Identified trends and patterns.
* Visualized distributions and relationships.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Corrected inconsistent data.
* Converted data types where required.
* Treated outliers when necessary.

### 4. SQL Analysis

* Imported data into SQL databases.
* Wrote SQL queries for analysis.
* Used:

  * SELECT
  * WHERE
  * GROUP BY
  * ORDER BY
  * JOIN
  * Aggregate Functions
  * Subqueries
  * Window Functions (where applicable)

### 5. Dashboard Development

* Connected Power BI to the cleaned dataset.
* Created interactive dashboards.
* Added filters and slicers.
* Built KPI cards and visualizations.

### 6. Reporting

* Documented the analysis process.
* Summarized key findings.
* Prepared a presentation using Gamma.
* Finalized the presentation in PowerPoint.
